# Pill Tracker

A private, offline web app for tracking daily supplements and medications.

- Daily schedule with one-tap "Take" logging and undo
- Pill counts that go down as you log, with low-supply warnings
- Reminders: downloadable calendar file (.ics) with daily alarms and refill reminders, plus notifications while the app is open
- 14-day history and backfill for forgotten logs
- Backup and restore as a JSON file

All data stays in the browser on your phone (localStorage). There is no server, account or analytics.

## Install on your phone

Open the GitHub Pages URL, then:
- **iPhone (Safari):** Share → Add to Home Screen
- **Android (Chrome):** menu → Install app / Add to Home screen

After the first open it works offline.
